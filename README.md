# Andina Explora ⛰️

Página web educativa e interactiva sobre la Región Andina de Colombia.

## Base del proyecto
- Ciencias Sociales — Grado 11°
- Trabajo colaborativo
- Diseño responsive para celular, tablet y computador
- Secciones preparadas según el proyecto escolar
- Espacios para video, podcast, infografías y PowerPoint
- Tres actividades interactivas preparadas para desarrollar
- Sección de recursos externos y fuentes consultadas
